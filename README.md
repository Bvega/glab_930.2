# GLAB 930.2 - Exploring LLM Use Cases in Customer Support

This repository contains the completed Per Scholas GLAB 930.2 guided lab. The lab examines practical customer-support uses for large language models, their limitations, effective prompting, ethical considerations, a real-world case study, and implementation lessons.

## Folder structure

- `instructions/` - Original assignment PDF and supplied Per Scholas Word template.
- `report/GLAB_930.2_Transcript.md` - Chronological record of the six task prompts, AI responses, and Task 3 experiments.
- `report/GLAB_930.2_Report_Bolivar_Vega.docx` - Completed report prepared from the supplied template.
- `screenshots/` - Twelve authentic screenshots documenting the recorded lab interactions.

## Completed tasks

1. Explored practical LLM applications in customer support.
2. Identified limitations involving context, accuracy, emotion, domain knowledge, system access, and authority.
3. Reviewed prompting techniques and compared a vague return prompt with a detailed, policy-grounded prompt.
4. Examined privacy, fairness, transparency, accountability, human oversight, respect, autonomy, and accessibility.
5. Reviewed Klarna as a customer-support case study and documented source limitations.
6. Summarized the main lessons and included the learner's reflection.
